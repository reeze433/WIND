# WIND

Игровая система для Foundry Virtual Tabletop 14. Текущая версия: 0.3.0; проверенная сборка Foundry: 14.368.

## Установка

В Foundry откройте главное меню, «Игровые системы» → «Установить систему» и вставьте адрес манифеста:

```
https://github.com/reeze433/WIND/releases/latest/download/system.json
```

Подробности и ручная установка: [INSTALL.md](docs/INSTALL.md).

## Возможности

- Листы персонажей и противников, шесть характеристик и символические броски.
- Предметы и особенности с режимами действий, зарядами и ресурсами.
- Карточки чата с повторными бросками, ответными проверками и применением значения мастером.
- Инвентарь списком, подготовка предметов, режим просмотра/редактирования и форматированные описания.
- Русский интерфейс, темы оформления и интеграции с дополнительными модулями.

Миры, персонажи и библиотека материалов кампании в пакет не входят. Дополнительные модули устанавливаются отдельно. ID пакета `vitruviy` сохранён для совместимости существующих миров.

## Разработка
