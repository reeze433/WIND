# Разработка WIND

Требуются Node.js 22+ и Python 3. Установите зависимости проверки:

```sh
npm ci
npm test
npm run verify
python build_release.py
```

Тесты запускаются отдельными процессами, чтобы изолировать глобальные моки Foundry. Проверка владельцев с реальными методами Foundry опциональна: задайте `FOUNDRY_APP_PATH` равным папке приложения, содержащей `common/abstract/document.mjs`. Без установленного Foundry эта одна интеграционная проверка пропускается. Проприетарный код Foundry в репозитории не распространяется.

ZIP и манифест создаются в `releases/`. Версия и адрес ZIP берутся из `system/system.json`. Для следующего релиза обновите `version` и `download` и создайте соответствующий тег `vX.Y.Z`. Workflow проверит код и опубликует ZIP и system.json в GitHub Releases.

История локальной кампании, скриншоты, резервные копии, PDF правил и данные серверов исключены из Git через список разрешённых путей в .gitignore.
