# Установка WIND

Требуется Foundry VTT 14, проверенная сборка 14.368.

## По ссылке

1. Откройте главное меню Foundry → Игровые системы → Установить систему.
2. Вставьте Manifest URL: `https://github.com/reeze433/WIND/releases/latest/download/system.json`.
3. Установите WIND и создайте мир с этой системой.

## Вручную

Скачайте `vitruviy-0.3.0.zip` из GitHub Releases. При выключенном Foundry распакуйте папку `vitruviy` в пользовательский каталог `Data/systems/`. Итоговый путь: `Data/systems/vitruviy/system.json`.

## Обновления

Сделайте резервную копию мира, сохраните открытые формы и обновите WIND из главного меню Foundry. Участникам после обновления нужно перезагрузить страницу через Ctrl+F5.

Технический ID системы остаётся `vitruviy`. Данные миров, персонажи, изображения кампании и лицензия Foundry в дистрибутив не входят.
